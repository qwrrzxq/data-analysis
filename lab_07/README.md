# Лабораторна робота №7

## Computer Vision та багатопотоковість у C++

### Опис

Продовження лабораторної роботи №6. Додано детекцію облич на базі ResNet-10 SSD (cv::dnn) з винесенням інференсу в окремий потік для збереження плавності відео.

### Вимоги до системи

- **ОС:** Ubuntu 20.04+ / Debian 11+
- **Компілятор:** GCC 9+ (g++) з підтримкою C++17
- **CMake:** 3.10+
- **OpenCV:** 4.x з модулем dnn
- **Камера:** веб-камера (USB або вбудована)

### Інструкція із запуску

```bash
# 1. Встановити залежності та завантажити модель
./preinstall.sh

# 2. Зібрати проєкт
./build.sh

# 3. Запустити програму
./run.sh
```

### Багатопотоковість

Детекція облич працює в окремому потоці (`std::thread`). Основний потік (UI) залишається плавним (30-60 FPS), а рамки навколо облич оновлюються асинхронно.

**Main Thread (UI):**
1. Читає кадр з камери
2. Відправляє копію кадру в `FaceDetector` (під м'ютексом)
3. Забирає останні координати облич (під м'ютексом)
4. Малює рамки на поточному кадрі
5. Відображає результат

**Worker Thread (Background):**
1. Чекає на новий кадр (`std::condition_variable`)
2. Запускає `net.forward()` (інференс нейромережі)
3. Оновлює координати знайдених облич (під м'ютексом)
4. Повторює цикл

Синхронізація: `std::mutex` + `std::condition_variable` + `std::atomic<bool>`.

### Демонстрація багатопотоковості

Клавіша `d` вмикає штучну затримку 500мс в детекторі облич. Це дозволяє наочно показати перевагу багатопотокового підходу: навіть при значній затримці інференсу відео залишається плавним, а рамки облич просто оновлюються рідше.
